# Vortex States in Ginzburg Landau

Code used in the paper "The Ginzburg-Landau equations: Vortex states and numerical multiscale approximations" 

Results are calculated using the routine "main_compute_minimizer.m":

1. set configuration in "main_compute_minimizer.m"
2. run "main_compute_minimizer.m"

Set "parallel=true" if Parallel Computing Toolbox is available. Tested with MATLAB version R2023b.
